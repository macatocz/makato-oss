build-fix-ci: approved implementation plan

Approved by the user's instruction to implement the analyzed CI repair plan.

Goal alignment

makato-build transforms planned stories into tested, reviewed code. This skill closes the remote CI feedback loop after an existing PR is created or updated.

Inputs and result

Work-item key, PR number, repository, isolated worktree, plugin roots and spec context. Result: current-head green or an explicit non-success with unresolved checks and resumable progress.

Workflow

  1. Open audit and recover the private PR-scoped checkpoint.
  2. Inspect all checks and required contexts for the exact PR head; retrieve exact run/job/attempt diagnostics.
  3. Route all actionable failures through sensor, TDD, goal-mode or metadata recovery.
  4. Independently review and verify source repairs, then push to the existing PR without recursion.
  5. Re-inspect new-head CI until green, blocked, cancelled, timed out or stalled.

Routing

This is a PR phase coordinator, not a mid-task coding reference. Both glob-bundle and task-archetype injection are intentionally skipped. Autonomous create-pr and the PO-agent explicitly dispatch the skill through the existing role-aware runner.

Validation

Behavioral GitHub API boundary tests, live read-only inspection, an isolated draft sandbox PR with failing then passing CI, skill frontmatter/self-containment, state and workflow checks.
