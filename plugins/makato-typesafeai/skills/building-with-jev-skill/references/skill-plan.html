Parent plugin goal — makato-typesafeai Provide reference skills and patterns for building AI-powered applications with TypeSafe's System One model API.

How this skill serves the goal

The how-to-typesafe-ai skill covers the "what and why" of TypeSafe's programming model. building-with-jev-skill covers the "how to do it correctly" — Jev-specific question design, primitive selection, state construction, composition patterns, confidence thresholds, and debugging failed questions. Together they form a complete reference: concept + execution.

Content

SKILL.md sections

Sections (verbatim from provided content)

  • Introduction — Jev model framing: parallel answers, probability distributions, code owns control flow
  • Workflow — 7-step process: list decisions → write questions → pick primitive → build state → batch → compose in code → test
  • Choose the primitive — Choice / Score / Noul comparison table with guidance notes
  • Write the instructions — exact-condition rules, structured instructions object with JSON example
  • Write the criteria — Choice, Score, and Noul criteria patterns with JSON examples
  • Build the state — filtering, token budget (64k / 32k), adversarial state note
  • Compose the answers in code — speculative fan-out, confidence-gated routing, composite scoring, taxonomy walk, counting, extraction — with complete Python example
  • Read the answers — score semantics, confidence meaning, Noul distance from 0.5
  • Improve a program — symptom/cause/fix table (13 rows)
  • Checklist — 12-item pre-ship checklist
  • Sources — live docs links
