Goal Alignment

Does this skill serve the plugin's goal?

Plugin Goal Ensure every pull request merged to main meets quality, security, and convention standards without requiring manual reviewer bandwidth for routine checks.

How This Skill Serves the Goal

The code-reviewer skill automates the first pass of PR review by scanning changed files for convention violations (naming, import order, file structure), known anti-patterns (N+1 queries, unhandled promise rejections, hardcoded secrets), and documentation gaps. It produces a structured review comment directly on the PR, freeing human reviewers to focus on architectural decisions and business logic correctness.

Position in Plugin Workflow

This skill runs after CI passes and before human review assignment. It gates the review queue — PRs with critical findings are flagged and held, while clean PRs proceed to the reviewer pool with a "pre-approved on conventions" badge.
