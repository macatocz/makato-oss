Goal Alignment
decompose
Plugin Goal (makato-plan)

Transforms raw Jira features into PI-sized epics with vertically-sliced stories through structured discovery, interviews, and architectural analysis.

How this skill serves the goal: Takes the pland artifacts (PRD + architecture + prototype) and decomposes them into independently deliverable, vertically-sliced stories with acceptance criteria. This is Phase 5 of the pipeline — the final transformation before stories become Jira issues.

Position in pipeline: brainstorming → create-prd → create-architecture → create-prototype → decompose → publish-*

Core Philosophy
Vertical Slicing Rules
Fundamental Test

"Can a user do something new when this story is complete, without waiting for any other story?"

Nine Splitting Patterns

#PatternExample
1Workflow StepsBreak multi-step flows into individual end-to-end steps
2Operations (CRUD)Split "Manage X" into Create, Read, Update, Delete
3Business Rule VariationsSeparate rules into distinct stories
4Data VariationsStart with simplest data plan, expand later
5Data Entry MethodsSimple input first, enhance later
6Major Effort"Support one type" then "support all types"
7Simple/ComplexExtract happy-path, defer edge cases
8Defer PerformanceMake it work, then make it fast
9Break Out a SpikeTime-box research when uncertainty is high

Behavior Constraints

  • Max 3 findings per story — pragmatic, not perfectionistic
  • If a story is fine, say "No concerns"
  • Iteration 2: Focus only on whether previous concerns were addressed
  • Natural endpoint: max 2 iterations OR "good enough" OR no new high-severity findings

HTML Review

Color-coded callout boxes: PO (blue), Dev (green), QA (amber). Each story rendered as a Jira card with agent feedback alongside. Per-slide comment textarea + "Copy Feedback" button.
