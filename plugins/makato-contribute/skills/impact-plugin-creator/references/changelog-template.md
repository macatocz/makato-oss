# CHANGELOG.md Template

Generate the following:

```markdown
# Changelog — <plugin-name>

## [0.1.0] — <YYYY-MM-DD>

### Added
- Initial plugin with governance files
- Plugin manifest (plugin.json)
- Contributor guide (AGENTS.md)
```

Rules:
- Use today's date in ISO format (YYYY-MM-DD)
- If .mcp.json was generated, add: `- MCP server declarations (<server-names>)`
- Keep the initial entry minimal — document what was created, not what will be
