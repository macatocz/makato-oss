# makato Product Direction

> **Scope**: Mission, vision, and roadmap themes for the makato suite.
> `context-scout` surfaces this as **Critical**-tier "product direction" context
> during brainstorming and PRD authoring — it is always relevant for ideation.

## Mission

makato provides a **full development cycle for building applications following a
driven-spec approach**: from raw feature request, through structured planning,
to tested and merged code — increasingly unattended.

## Suite themes

- **Spec-driven**: every unit of work traces back to a spec folder under
  `specs/<key>-<slug>/` and a decomposed, vertically-sliced GitHub issue.
- **Autonomous-by-default**: the orchestrate control plane drives Ready issues to
  merged PRs without human babysitting, halting on documented HALT codes.
- **Skill-routed**: agents receive recommended skills automatically; adoption is
  audited and refined over time (the `agent-skill-routing` epic).
- **Harness-independent** (in progress): the suite is being decoupled from any
  single Claude Code harness so it can run on alternative agent runtimes.
